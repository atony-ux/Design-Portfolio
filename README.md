# Anthony N. — Portfolio 2.0

An elevated rebuild of the portfolio: same blue-duotone + hand-drawn creative
direction from the brief, pushed further on layout, motion, and the recurring
mascot character.

## Pages
- `index.html` — home (hero, selected works bento, AI-native process, contact footer)
- `about.html` — about, toolkit, experience timeline, **hobbies** bento, street-scene band
- `works.html` — interactive editorial work index (cursor-follow preview + filters)
- `work/vendrs.html`, `work/qac-gallery.html`, `work/uc-davis-app.html` — case studies

## What's new in 2.0
- **Mascot everywhere** — nav dot, hero, process board, footer wave, page-transition
  wipe, and a persistent floating "buddy" companion with speech bubbles.
- **Motion** — preloader, blue page-transition wipe between pages, split-line hero
  reveal, scroll reveals + counters, magnetic buttons, 3D card tilt, custom cursor
  with a "View" label, rotating hero text ring, marquee + giant footer wordmark.
- **Showcasing variety** — home uses the noren (shop-curtain) card reveal; the Works
  page uses an editorial hover-preview list, keeping one consistent system.
- **Hobbies** — real acrylic paintings shown in full colour (an intentional pop
  against the all-blue palette), plus coffee, travel, character art, and music.
- **Big Leah-Kim-style footer** — oversized "Let's talk", scrolling wordmark, and a
  faint street-lamp silhouette across the base.

## Design tokens
Defined once in `css/style.css` `:root` — brand blue `#213c97`, backgrounds,
IBM Plex Serif (italic accents) + Overused Grotesk (body), radii, shadows, motion.
